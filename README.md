# my-first-todo
My first JavaScript To-Do List app — built while learning DOM manipulation, ES modules, events, and localStorage.

I felt the pain of DOM manipulation firsthand, and now I understand why frameworks like React become so interesting — like, Why am I manually updating all this HTML? 

# What I learned 

- JavaScript DOM manipulation
- ES Modules
- Event handling
- localStorage
- Array methods
- Dynamic task rendering
- Basic project structure

# Features

- Add tasks
- Delete tasks
- Active tasks
- Complete tasks
- Today's tasks
- Upcoming tasks
- Completed tasks
- Task statistics
- Persistent tasks using localStorage
